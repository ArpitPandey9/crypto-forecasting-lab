# Crypto Forecasting Lab

Experimental notebook-based workspace for exploring cryptocurrency forecasting ideas and model behavior.

## Tracked notebooks

- `S&P Quant day 2 Ethereum analysis alongside Bitcoin.ipynb`
- `S&P_Quant_Day1.ipynb`

## Scope

This repository preserves exploratory research notebooks. The notebooks are the source of truth for the exact data, features, models, assumptions, and outputs used in each experiment.

No claim of production readiness, durable predictive edge, trading alpha, or validated investment performance is made.

## Reproducibility

Notebook outputs can depend on package versions, external data providers, execution date, and notebook state. Re-run an experiment in a controlled environment before treating historical notebook output as current evidence.

## Limitations

This is an educational research workspace, not an investment recommendation, production forecasting system, or representation of any employer or client.
